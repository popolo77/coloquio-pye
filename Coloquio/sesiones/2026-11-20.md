## Bloque 1: Variable aleatoria, f(x), F(x), E(x), V(x) y DS(x)

### 1. Idea simple
Una **variable aleatoria (VA)** le asigna un número a cada resultado de un experimento aleatorio.
- Ejemplo: X = cantidad de requests que llegan a la API en 10 segundos.

| Tipo | Qué valores toma | Ejemplo en sistemas |
|---|---|---|
| **Discreta** | Valores aislados que se cuentan (0, 1, 2…) | Requests, bugs, logs de error |
| **Continua** | Cualquier valor de un intervalo | Latencia en ms, tiempo de respuesta |

### 2. Cómo se escribe

| Símbolo | Qué es | Qué pregunta responde |
|---|---|---|
| **f(x) = P(X = x)** | Función de cuantía | ¿Qué probabilidad tiene exactamente ese valor? |
| **F(x) = P(X ≤ x)** | Función acumulada | ¿Qué probabilidad hay de que sea **como máximo** x? |
| **E(x) = Σ x·f(x)** | Esperanza | ¿Cuál es el valor promedio **a largo plazo**? |
| **V(x) = Σ (x − E(x))²·f(x)** | Varianza | ¿Cuánto se dispersan los valores alrededor de E(x)? |
| **DS(x) = √V(x)** | Desvío estándar | La dispersión, medida en la misma unidad que X |

### 3. Ejemplo paso a paso: requests en 10 s

| x | f(x) | F(x) | x·f(x) | (x−2)²·f(x) |
|---|---|---|---|---|
| 0 | 0,20 | 0,20 | 0 | 0,80 |
| 1 | 0,15 | 0,35 | 0,15 | 0,15 |
| 2 | 0,30 | 0,65 | 0,60 | 0 |
| 3 | 0,15 | 0,80 | 0,45 | 0,15 |
| 4 | 0,20 | 1,00 | 0,80 | 0,80 |
| **Σ** | **1** | | **E = 2** | **V = 1,90** |

DS = √1,90 ≈ **1,378 requests**.

```
f(x)
0,30 |        ███
0,20 |  ███   ███         ███
0,15 |  ███ ███ ███ ███   ███
     +--------------------------
        0    1    2    3    4    ← x (requests)
                  ↑ E(x) = 2
```

```r
x  <- 0:4
fx <- c(0.20, 0.15, 0.30, 0.15, 0.20)   # función de cuantía
sum(fx)                                  # tiene que dar 1
cumsum(fx)                               # F(x) acumulada
E  <- sum(x * fx)                        # esperanza → 2
V  <- sum((x - E)^2 * fx)                # varianza → 1.9
DS <- sqrt(V)                            # desvío → 1.378
barplot(fx, names.arg = x, main = "Requests cada 10 s")
```

### 4. Ojo con...
- ⚠️ **E(x) no es "lo que pasa siempre".** Es el promedio de largo plazo. P(X = 2) es apenas 0,30.
- ⚠️ La **V(x)** está en unidades al cuadrado. Para interpretar se usa la **DS(x)**.
- ⚠️ La suma de todos los **f(x) da 1**, y **F(x)** nunca baja: solo crece o se mantiene.
- ⚠️ En una VA **continua**, P(X = un valor exacto) = 0. Ahí se trabaja con intervalos.
