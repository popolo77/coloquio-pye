## Bloque 1: Variable aleatoria, f(x), F(x), E(x), V(x) y DS(x)

### 1. Idea simple
Una **variable aleatoria** representa numéricamente a cada posible resultado de un experimento aleatorio (definición de la cátedra).
Una **distribución de probabilidad** muestra, con una tabla, un gráfico o una fórmula, todos los valores que puede asumir la variable y la probabilidad de cada uno.
- Ejemplo: X = cantidad de requests que llegan a la API en 10 segundos.

| Tipo | Qué valores toma | Ejemplo en sistemas |
|---|---|---|
| **Discreta** | Valores aislados que se cuentan (0, 1, 2…) | Requests, bugs, logs de error |
| **Continua** | Cualquier valor de un intervalo | Latencia en ms, tiempo de respuesta |

### 2. Cómo se escribe

| Símbolo | Qué es | Qué pregunta responde |
|---|---|---|
| **f(x) = P(x = xᵢ)** | Función de cuantía | ¿Qué probabilidad tiene exactamente ese valor? |
| **F(x) = P(X ≤ x) = Σ f(x)** | Distribución acumulada | ¿Qué probabilidad hay de que sea **como máximo** x? |
| **E(x) = Σ x·P(x)** | Esperanza matemática (valor esperado) | Promedio ponderado de los valores, con las probabilidades como pesos |
| **V(x) = Σ x²·P(x) − [E(x)]²** | Varianza (fórmula simplificada de la cátedra) | Promedio ponderado de los desvíos al cuadrado respecto de E(x) |
| **DS(x) = √V(x)** | Desviación | Dispersión promedio entre los valores de x y E(x), en la misma unidad que x |

### 3. Ejemplo paso a paso: requests a la API en 10 s
(Es el ejemplo de la cátedra con clientes de un restaurante, cambiando "clientes" por "requests".)

| x (requests) | P(x) | F(x) | x·P(x) | x²·P(x) |
|---|---|---|---|---|
| 0 | 0,15 | 0,15 | 0 | 0 |
| 1 | 0,25 | 0,40 | 0,25 | 0,25 |
| 2 | 0,25 | 0,65 | 0,50 | 1,00 |
| 3 | 0,20 | 0,85 | 0,60 | 1,80 |
| 4 | 0,10 | 0,95 | 0,40 | 1,60 |
| 5 | 0,05 | 1,00 | 0,25 | 1,25 |
| **Σ** | **1** | | **E(x) = 2** | **5,90** |

- E(x) = 2
- V(x) = 5,90 − (2)² = **1,90**
- DS(x) = √1,90 = **1,378 requests**

```
P(x)
0,25 |      ███  ███
0,20 |      ███  ███  ███
0,15 | ███  ███  ███  ███
0,10 | ███  ███  ███  ███  ███
0,05 | ███  ███  ███  ███  ███  ███
     +-------------------------------
        0    1    2    3    4    5   ← x (requests)
                  ↑ E(x) = 2
```

```r
x  <- 0:5
px <- c(0.15, 0.25, 0.25, 0.20, 0.10, 0.05)  # función de cuantía
sum(px)                                       # tiene que dar 1
cumsum(px)                                    # F(x) acumulada
E  <- sum(x * px)                             # E(x) → 2
V  <- sum(x^2 * px) - E^2                     # V(x) → 1.9 (fórmula de la cátedra)
DS <- sqrt(V)                                 # DS(x) → 1.378
barplot(px, names.arg = x, main = "Requests cada 10 s",
        xlab = "x (requests)", ylab = "P(x)")
```

### 4. Ojo con...
- ⚠️ **E(x) no es "lo que pasa siempre".** Es un valor promedio esperado. P(x = 2) es apenas 0,25.
- ⚠️ La **V(x)** está en unidades al cuadrado. Para interpretar se usa la **DS(x)**.
- ⚠️ La suma de todos los **f(x) da 1**, y **F(x)** nunca baja: solo crece o se mantiene.
- ⚠️ En una VA **continua**, P(X = un valor exacto) = 0. Ahí se trabaja con intervalos.
